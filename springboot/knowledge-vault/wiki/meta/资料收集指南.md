## 📥 如何添加资料

### 方法一：手动下载并放置

1. **下载资料到本地**
2. **放入对应文件夹**：
   ```
   学术论文     → .raw/papers/
   网页文章     → .raw/webpages/
   田野笔记     → .raw/fieldnotes/
   文物照片     → .raw/photos/
   AI对话记录   → .raw/conversations/
   其他文章     → .raw/articles/
   ```

3. **在 Claude CLI 中处理**：
   ```
   ingest .raw/papers/三星堆青铜器研究.pdf
   ```

### 方法二：使用 Obsidian Web Clipper

**安装 Web Clipper**：
1. 浏览器扩展商店搜索 "Obsidian Web Clipper"
2. 安装并配置到你的 vault

**使用方法**：
1. 浏览网页时点击 Clipper 图标
2. 选择保存位置：`.raw/webpages/`
3. 自动转换为 Markdown 格式

**适合内容**：
- 博物馆网页介绍
- 考古新闻报道
- 研究机构简介
- 在线文章

### 方法三：批量添加

将多个文件放入 `.raw/` 对应文件夹后：
```
ingest all of these
```

AI 会自动处理所有新文件。

## 📋 资料命名规范

### 文件命名建议

**学术论文**：
```
作者_论文标题_年份.pdf
例：赵殿增_三星堆青铜器铸造技术研究_2020.pdf
```

**考古报告**：
```
遗址名_发掘单位_年份.pdf
例：三星堆_四川省考古所_1999.pdf
```

**网页资料**：
```
网站名_页面标题_日期.md
例：三星堆博物馆_青铜神树介绍_20260703.md
```

**图片资料**：
```
文物名_拍摄角度_编号.jpg
例：青铜神树_正面_001.jpg
```

## ✅ 添加资料后的流程

### 1. AI 自动处理

当你执行 `ingest` 后，AI 会：
- 阅读并理解资料内容
- 创建资料摘要页面（`wiki/sources/`）
- 提取实体信息（遗址、文物、人物）
- 提取概念信息（技术、理论）
- 建立交叉引用
- 更新现有条目
- 更新索引和日志

### 2. 生成的内容

每个资料通常会生成：
- 1 个源文档摘要
- 3-8 个实体条目（新建或更新）
- 2-5 个概念条目（新建或更新）
- 若干交叉引用链接

### 3. 质量控制

添加资料后检查：
- `wiki/log.md` — 查看处理记录
- `wiki/index.md` — 查看新增条目
- `wiki/hot.md` — 查看最新摘要

## 💡 使用技巧

### 优先添加什么？

**第一批（基础资料）**：
- 三星堆、金沙遗址的综合介绍
- 重要文物的详细说明
- 基础考古报告

**第二批（深入研究）**：
- 专项研究论文（工艺、纹饰、年代等）
- 对比研究论文
- 最新考古发现

**第三批（拓展视野）**：
- 相关遗址资料
- 区域文化背景
- 跨文化比较

### 如何高效收集？

1. **设定主题**：每次聚焦一个主题收集
   - 如：本周收集"青铜铸造工艺"相关资料
   
2. **批量处理**：一次收集5-10篇相关资料，批量 ingest

3. **质量优先**：优先添加学术质量高的资料

4. **图文并茂**：文献 + 图片一起添加效果更好

## 📝 注意事项

1. **版权问题**：
   - 学术资料仅用于个人研究
   - 不要公开分享受版权保护的 PDF

2. **文件格式**：
   - PDF 最佳（论文、报告）
   - Markdown 次之（网页）
   - 图片支持 JPG, PNG

3. **文件大小**：
   - 单个文件建议不超过 50MB
   - 大型资料可以分卷

4. **资料质量**：
   - 优先选择学术性强的资料
   - 网页资料注意可信度
