# 三星堆竞赛项目 · 当前完成汇报

## 一、项目概览

在原「三星堆非遗文化平台」基础上，面向竞赛进行前端重构 + 后台升级，核心目标是将一个通用文化展示平台转变为**以古蜀时空探索为叙事主线的交互式数字展陈系统**。

原项目是一个功能齐全的非遗文化综合平台（文物/活动/课程/商城/用户管理），竞赛版本在此之上新增了一条独立的前端竞赛演示链路，原平台功能完全保留。

---

## 二、竞赛核心链路（全新）

新增了 5 个前端页面的竞赛闭环：

```
首页 → 时空探索 → 文物筛选 → 3D 交互 → AI 解读
```

| 页面 | 文件 | 说明 |
|------|------|------|
| 首页 | `vue3/src/views/frontend/Home.vue` | 竞赛主题 Hero + 4 步预览卡片（时空探索/文物展厅/3D 舞台/AI 解说），引导进入竞赛流程 |
| 时空探索 | `vue3/src/views/frontend/tanmi.vue` | 三轴交互筛选器：时期（时间轴）、遗址（卡片组）、工艺（标签云），选中后动态过滤文物结果集 |
| 文物列表 | `vue3/src/views/3ddemo.vue` | 文物卡片网格，展示 5 件旗舰文物，支持跳转 3D 模型页 |
| 3D 交互 | `vue3/src/views/Three3dDemo.vue` | Three.js 3D 模型加载 + SVG 知识图谱（文物→遗址→时期→工艺→寓意）+ 文物档案面板 |
| AI 解读 | `vue3/src/views/frontend/AiChat.vue` | 流式 AI 对话 + 文物上下文注入 + 定制提问建议 |

**共享数据层：** `vue3/src/data/competitionArtifacts.js` + `vue3/public/data/competition-artifacts.seed.json`（5 件文物结构化数据）

**路由参数契约：** 全链路用 `entityId` + `glbUrl` 贯通，确保文物身份一致。

## 四、玄喵虚拟角色（Live2D）

在前端右下角新增了虚拟导游「玄喵」：

- **Live2D 角色渲染**：CDN 加载 hijiki 模型，支持点击交互
- **AI 对话气泡**：打字机效果 + TTS 语音合成（SiliconFlow CosyVoice2）
- **音色选择**：3 种音色可选（默认男声 alex / 标准女声 bella / 甜美女声 anna）
- **固定问答匹配**：内置三星堆关键词回复（青铜神树、黄金面具、皮影戏等）
- **WebSocket AI 对话**：接入讯飞星火大模型，支持流式问答
- **自动隐藏/唤出**：30 秒无操作自动收起，侧边标签唤出

修复了多个 bug：文字截断、消失逻辑、音色切换、面板重叠点击等。

## 七、当前缺口

| 优先级 | 缺口 | 影响 |
|:--:|------|------|
| 🔴 致命 | 时空筛选 API 未写 | 评委操作筛选器时底层数据不动 |
| 🔴 致命 | 文物表缺竞赛扩展字段 | 后端无法存储/查询竞赛维度的文物数据 |
| 🟡 重要 | 图谱查询 API 未写 | 3D 页图谱是前端硬画 SVG，非真实数据 |
| 🟡 重要 | AI 文物解读 API 未写 | AI 回答用的是通用对话，缺少专业 RAG |
| 🟢 锦上 | 金杖 GLB 模型缺失 | 临时共用金面具资源 |

**数据链路现状：** 5 个竞赛页面中有 4 个的数据来自前端本地 JSON 文件，而非后端 API。
