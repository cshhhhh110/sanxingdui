二、玄喵虚拟角色（Live2DAvatar）—— 大幅升级
================================================================

文件：vue3/src/components/Live2DAvatar.vue

原状态：固定关键词匹配 → WebSocket(讯飞星火) → 打字机 → TTS
现状态：固定问候兜底 → RAG 知识检索 → 后端 SSE 流式 → 思考态动画 → 打字机 → TTS

新增功能：
  1. RAG 知识检索
     - searchKnowledge + buildRagPrompt + buildFallbackReply
     - 7 份本地知识文档（见"知识库"章节）
     提问流程：searchKnowledge→buildRagPrompt→SSE 流式→打字+语音

  2. 浏览器语音输入
     - Web Speech API 封装（browserSpeech.js）
     - 对话框左下角"语音提问"按钮
     - 不支持时自动禁用、识别中显示"停止听写"

  3. 思考等待态
     - 8 条轮播提示语（"玄喵正在思考中…"等）
     - 每 2.4 秒切换，收到首 token 后停止

  4. TTS 语音播放
     - 打字速度与音频时长动态同步
     - TTS 失败时降级为纯打字机
     - 播放完毕自动触发气泡隐藏

  5. 会话管理
     - ensureChatSession() 自动创建/复用后端会话
     - AbortController 支持中断进行中的请求

  6. 三层兜底
     - 知识未命中 → "不确定，不要编造"
     - SSE 失败 → buildFallbackReply 简短判断
     - 全链路断 → "喵～我的小脑袋有点晕"

  7. UI 细节
     - 音色下拉选择（持久化 localStorage）
     - 对话框可拖拽
     - 30 秒无交互自动隐藏
     - 点击停止播放

清理：
  - 已删除 WebSocket 相关全部死代码（initWS/handleMessage/ws/wsReconnectTimer）

五、MiMo 大模型接入
================================================================

配置：application.yml（mimo 段）

用途：
  - TTS 语音合成：mimo-v2.5-tts（通过 Chat 格式接口，api-key 头鉴权）
  - AI 对话备选：mimo-v2.5-pro（OpenAI 兼容协议，按需切换）

TtsService.java 改造：
  - 多 Provider 架构（siliconflow | mimo），通过 tts.provider 配置切换
  - MiMo 三套音色：苏打(默认男声) / 冰糖(女声) / 茉莉(甜美女声)
  - SiliconFlow 三套音色：alex / bella / anna
  - GET /tts/voices 返回当前 provider 的音色列表

AI 对话链路：
  - 主力：Spring AI → SiliconFlow DeepSeek-V3（application.yml spring.ai.openai 段）
  - MiMo chat 模型已配置可随时切换
