# 开发与目录说明

这份文档帮助开发者快速找到页面、接口、Agent、RAG和测试代码。

## 1. 目录结构

```text
springboot/
├── src/main/java/org/example/springboot/
│   ├── agent/          Agent Router、工具注册和编排
│   ├── ai/             AI文博助手和提示词
│   ├── controller/     REST 接口和 SSE 接口
│   ├── dto/             请求与响应对象
│   ├── entity/          数据库实体
│   ├── knowledge/       Markdown解析、索引和检索
│   ├── mapper/          MyBatis-Plus Mapper
│   ├── service/         会话、文件、多模态、图谱和业务服务
│   └── config/           数据库、模型、安全和跨域配置
├── src/main/resources/
│   ├── application-template.yml
│   └── mapper/
└── knowledge-vault/wiki/ 文博 Markdown 知识库

vue3/
├── src/views/            前端页面
├── src/components/       公共组件、三维和虚拟导游组件
├── src/agent/             Agent上下文、状态和导览编排
├── src/api/               后端 API 封装
├── src/mcp/               前端工具执行层
├── src/utils/             知识检索和通用工具
├── public/glbs/           GLB 文物模型
├── public/data/           前端种子数据和知识文本
└── scripts/               Agent/UI 回归脚本

docs/                       架构、数据、测试和运行说明
scripts/                    项目级辅助脚本
data/                       种子数据
heritage_db.sql             数据库初始化脚本
```

## 2. 推荐阅读顺序

1. 根目录 `README.md`：安装、配置和启动；
2. `docs/项目架构说明.md`：系统边界和主要数据流；
3. `springboot/.../agent/AgentRouterService.java`：后端路由；
4. `springboot/.../knowledge/KnowledgeIndexService.java`：知识索引；
5. `vue3/src/agent/AgentOrchestrator.js`：前端状态编排；
6. `vue3/src/views/frontend/AiChat.vue`：问答页面和 SSE 消费；
7. `vue3/src/views/frontend/Three3dDemo.vue`：三维和图谱页面。

## 3. 关键接口

| 接口 | 作用 |
|---|---|
| `POST /api/ai-chat/stream` | SSE 流式问答 |
| `POST /api/agent/route` | Agent路由 |
| `GET /api/agent/knowledge/status` | 知识索引状态 |
| `GET /api/agent/knowledge/search` | 知识检索 |
| `POST /api/agent/knowledge/sync` | 同步知识索引 |
| `POST /api/file/upload/temp` | 上传临时附件 |
| 图谱相关接口 | 返回文物节点、边和邻居关系 |

普通接口使用 JSON；AI回答和 Agent事件通过 SSE 增量返回。前端 Vite 将 `/api` 和 `/files` 代理到后端 `8889` 端口。

## 4. 修改功能时的建议

### 修改知识检索

优先查看 `knowledge/` 包、知识库 Frontmatter 和引用回传字段。修改排序规则后，应验证标题精确匹配、标签命中、关联页面和来源展示。

### 修改Agent工具

同时检查工具注册、参数校验、Router提示词、前端工具执行和异常回传。新工具必须明确输入、输出、超时和失败状态，不要直接开放模型生成的任意函数名。

### 修改导览状态

同时检查 `currentArtifact`、`currentTrailNode`、`trailStatus`、`activeGuideState` 和前端页面恢复逻辑。Agent调用工具并不代表页面已经到达，页面完成切换后还需要回传真实状态。

### 修改多模态功能

检查附件类型、文件大小、解析结果和模型调用超时。图片、音频、视频和文档走不同的解析路径，失败时应回退到文本或元数据回答。

## 5. 数据与配置

- `heritage_db.sql`：基础数据库导入；
- `docs/sql/competition-p0.sql`：竞赛功能增量字段；
- `docs/neo4j-graph-seed.cypher`：可选图谱种子数据；
- `springboot/src/main/resources/application-template.yml`：后端配置模板；
- `springboot/src/main/resources/application.yml`：本地真实配置，不提交 Git。

## 6. 本地验证

```powershell
cd vue3
npm run build

cd ..\springboot
.\mvnw.cmd -DskipTests package
.\mvnw.cmd test
```

前端回归脚本位于 `vue3/scripts/`，后端测试位于 `springboot/src/test/`。测试前应确认数据库、模型服务和前后端端口配置正确。
