## 1. 系统是什么

“青铜数元”是一个围绕三星堆与古蜀文明设计的数字文博体验系统。它不是单一的聊天网站，而是把文物浏览、3D 展示、知识图谱、智能导览、语音交互、AI 多模态问答、文化创作、研学课程、知识挑战、文化活动和文创商城连接在一起。

系统中的 AI 文化伙伴叫“玄喵”。玄喵能够：

- 回答普通问题和文博知识问题。
- 结合当前页面、当前文物和最近对话理解“它”“这个文物”等上下文指代。
- 查阅本地知识库，并在回答完成后显示“资料来源”。
- 根据用户的参观时间、兴趣和已浏览记录规划导览路线。
- 打开指定页面、搜索商品、搜索文物、控制时空展线。
- 接收图片、音频、视频和文档，辅助理解用户提供的材料。
- 将回答转换为语音，并配合字幕进行讲解。
- 在适合用图片帮助理解时提出“视觉辅助建议”，经用户确认后生成示意图。

### 1.1 系统中的三种角色

| 角色 | 适合谁 | 主要权限 |
|---|---|---|
| 未登录游客 | 第一次打开系统的人 | 浏览首页、部分文物内容、3D 数字馆、时空展线和考古全景 |
| 普通用户 | 参观者、学生、普通体验者 | 使用 AI 文博助手、完整探秘、知识答题、活动报名、商城下单、个人中心等 |
| 管理员 | 内容运营和系统管理人员 | 进入后台管理用户、文物、专家、活动、课程、商品、分类和订单 |

> 注册页面创建的是普通用户账号。管理员账号应由已有管理员在后台创建或维护，不要把管理员密码提供给普通游客。

## 2. 开始使用前的准备

### 2.1 普通使用者需要准备什么

1. 推荐使用最新版 Microsoft Edge 或 Google Chrome。
2. 确认访问地址。当前本地演示地址通常为 `http://localhost:8800`。
3. 如果要使用 AI、答题、活动、订单或个人中心，请先注册并登录。
4. 如果要使用语音输入，请允许浏览器访问麦克风。
5. 如果要听玄喵讲解，请确认电脑未静音，浏览器允许网页播放声音。
6. 如果要上传文件，请先确认文件类型和大小符合页面限制。

### 2.2 首次授权麦克风

第一次点击麦克风时，浏览器通常会询问是否允许使用麦克风：

1. 点击地址栏旁边的权限提示。
2. 选择“允许”。
3. 如果误点“阻止”，点击地址栏左侧的站点设置图标。
4. 将“麦克风”修改为“允许”。
5. 刷新页面后重新尝试。

### 2.3 建议的屏幕和网络环境

- 桌面端建议使用 1920×1080 或更高分辨率。
- 手机和平板可以访问，但 3D、知识图谱和后台表格在桌面端体验更好。
- AI 回答、语音合成、多模态解析和 AI 生图依赖后端与外部模型服务，网络较慢时需要等待。

## 3. 五分钟快速上手

如果你第一次使用，不需要先理解全部菜单，按下面顺序体验即可。

### 第一步：打开首页

在浏览器中访问：

```text
http://localhost:8800
```

系统会自动进入首页。你会看到“玄喵引路 古蜀寻踪”。

### 第二步：注册普通账号

1. 点击右上角“注册”。
2. 填写用户名、密码、确认密码、邮箱、手机号和姓名。
3. 点击注册按钮。
4. 注册成功后返回登录页。
5. 使用刚才的用户名和密码登录。

### 第三步：体验时空展线

1. 回到首页。
2. 点击“步入时空展线”。
3. 在祭祀坑地图上点击一个带文物的标注，例如“青铜神树”或“金面具”。
4. 按页面引导依次进入“文物驻足”“展品现场”“玄喵讲解”。
5. 在 3D 展台拖动文物，查看知识图谱。
6. 在讲解台点击推荐问题或输入自己的问题。

### 第四步：使用 AI 文博助手

1. 点击顶部“AI文博助手”。
2. 输入：

```text
三星堆文明为什么会让人觉得神秘？
```

3. 等待回答完成。
4. 如果回答使用了知识库，回答下方会出现折叠的“资料来源”。
5. 点击“继续探索”中的推荐问题，体验连续对话。

### 第五步：让玄喵执行操作

打开右侧悬浮的玄喵，输入：

```text
打开商城搜索金面具文创
```

玄喵会调用工具，打开文创商城并带入搜索条件。它不只是回复文字，还会执行真实页面操作。

## 4. 注册、登录与找回密码

### 4.1 注册账号

入口：右上角“注册”，或直接访问 `/auth/register`。

填写要求：

| 字段 | 要求 |
|---|---|
| 用户名 | 3 至 50 个字符，不能与已有用户名重复 |
| 密码 | 6 至 100 个字符 |
| 确认密码 | 必须与密码一致 |
| 邮箱 | 必填，格式必须正确，不能与已有邮箱重复 |
| 手机号 | 可填写中国大陆 11 位手机号 |
| 姓名 | 用于系统中的用户信息展示 |

注册成功后，系统不会自动把普通账号变成管理员。

### 4.2 登录

入口：右上角“登录”，或直接访问 `/auth/login`。

1. 输入用户名或账号。
2. 输入密码。
3. 点击登录。

登录后的跳转规则：

- 普通用户进入前台首页。
- 管理员进入后台管理工作台。
- 普通用户不能访问 `/back` 后台页面。
- 管理员登录后主要使用后台，不能按普通用户方式进入前台业务页面。

### 4.3 找回密码

1. 在登录页点击“忘记密码”。
2. 输入用户名、邮箱、手机号、新密码和确认密码。
3. 系统会核验用户名、邮箱和手机号是否与账号一致。
4. 核验成功后重置密码。
5. 返回登录页，使用新密码登录。

### 4.4 退出登录

1. 点击右上角头像或用户名。
2. 点击“退出登录”。
3. 在确认窗口中点击“确认退出”。

退出后，AI 文博助手、订单、个人中心等登录功能将不能继续使用。

## 6. 首页的使用方法

首页是系统的总入口，适合第一次体验时使用。

### 6.1 进入核心导览

首页首屏有两个主要按钮：

- “步入时空展线”：进入完整的四幕式数字导览。
- “直接走进文物展厅”：跳过路线筛选，直接选择 3D 文物。

### 6.2 浏览精选文物

1. 向下滚动到“精选作品”。
2. 点击任意文物卡片，进入文物详情。
3. 点击“查看更多”进入完整“古蜀瑰宝”列表。

### 6.3 浏览课程和活动

- 在“在线课程”区域点击课程，进入课程详情。
- 在“近期活动”区域点击活动，查看时间、地点、内容和报名状态。

## 7. 三星堆探秘与考古全景

### 7.1 三星堆探秘

入口：顶部“ 三星堆探秘 ”，地址 `/tanmi`。

页面按文化阶段展示宝墩文化、三星堆祭祀坑、金沙祭祀遗址等内容。

基本操作：

1. 浏览不同文化阶段的时间、地点和简介。
2. 点击“查看详情”，进入对应遗址介绍页。
3. 点击考古全景按钮，进入该阶段的全景漫游。
4. 点击“立即体验”，进入“古蜀 AI 创作”。

### 7.2 考古全景漫游

入口：探秘页面的“考古全景漫游”，地址 `/archaeology-panorama`。

操作方法：

1. 等待全景场景加载完成。
2. 按住鼠标拖动，观察四周场景。
3. 使用滚轮缩放画面。
4. 点击场景中的热点，阅读发现历程、出土文物和补充资料。
5. 完成当前场景的热点后，点击“前往下一场景”。
6. 点击“遗址地图”查看场景位置；已解锁场景可以直接跳转。
7. 点击笔记入口查看探索记录，并按页面按钮导出。
8. 点击“返回”回到上一页，或点击“退出全景”结束全屏体验。

如果下一场景不能进入，通常是当前场景仍有“待探索热点”。先完成剩余热点即可。

## 8. 时空展线完整教程

入口：首页“步入时空展线”，或访问 `/trail`。

时空展线是系统最完整的参观流程，共四幕：

```text
第一幕：时空定点
    ↓
第二幕：文物驻足
    ↓
第三幕：展品现场
    ↓
第四幕：玄喵讲解
```

页面上方的“展线进度”会显示当前是第几幕。已经到达的步骤可以点击返回；尚未解锁的步骤不可直接跳过。

### 8.1 第一幕：时空定点

这一幕用于确定遗址、坑位、年代、工艺和文物线索。

#### 方法一：从祭祀坑地图进入

1. 在遗址俯瞰图上找到 `K1` 至 `K8` 坑位。
2. 点击坑位，右侧会显示该坑位的背景说明和代表文物。
3. 如果文物卡片显示“进入展线”，点击它可以进入第二幕。
4. 如果只显示“空间线索”，说明该项目用于背景说明，当前不能作为完整文物进入后续 3D 展线。

#### 方法二：使用筛选条件

1. 在“时代”中选择全部时代或具体时代。
2. 在“遗址”中选择全部遗址、三星堆或金沙等。
3. 在“工艺”中选择青铜、金器等工艺条件。
4. 观察结果说明和命中文物数量。
5. 点击“继续向前”进入文物列表。
6. 点击“重新定点”清空筛选。

还可以通过“导览线索”从坑位、器类和象征寓意继续缩小范围。

### 8.2 第二幕：文物驻足

1. 浏览筛选后出现的文物卡片。
2. 点击想看的文物。
3. 页面会把它设为“当前焦点”。
4. 点击进入展品现场，前往第三幕。
5. 如果文物有 3D 模型，页面会在后续显示数字展台；没有模型时仍可查看文字档案和关系资料。

### 8.3 第三幕：展品现场

这一幕由三部分组成。

#### 3D 展台

- 按住鼠标左键拖动：旋转文物。
- 使用鼠标滚轮：拉近或拉远。
- 如果显示“正在布置数字展台”，请等待进度完成。
- 如果模型加载失败，点击“重新加载”。

#### 文物档案

右侧会显示：

- 出土地。
- 年代。
- 类别。
- 工艺。
- 文物摘要。

#### 图谱探索器

1. 点击图谱中的节点，查看“这是什么”“它与谁相连”“下一步去哪里”。
2. 使用节点类型按钮筛选时空坐标、工艺、材质、象征和相关文物。
3. 点击“回到中心”重新聚焦当前文物。
4. 点击“重置视图”恢复默认位置和缩放。
5. 点击“全屏展示”放大图谱，按 `Esc` 或点击退出按钮返回。
6. 点击“继续听玄喵讲”，把当前图谱节点带入讲解。

### 8.4 第四幕：玄喵讲解

1. 点击“展开讲解”。
2. 可以先点击推荐问题，也可以在输入框中输入问题。
3. 按 `Enter` 或点击“发送”。
4. 玄喵会结合当前文物、遗址、年代、工艺和刚才点击的图谱节点回答。
5. 点击“回看 3D”可以返回上一幕查看模型。
6. 点击“收起讲解台”缩小聊天区域。
7. 完成一轮讲解后，可以“再走一条线索”或进入知识挑战。

### 8.5 玄喵陪游

页面上方有“玄喵陪游”面板：

- 点击“开启陪游”开始语音导览。
- 点击“暂停”暂时停止。
- 点击“继续”恢复。
- 点击“问玄喵”直接围绕当前文物提问。
- 点击“关闭”结束陪游。

### 8.6 用自然语言规划路线

在 AI 文博助手或玄喵中可以这样说：

```text
我第一次来三星堆，只有20分钟，帮我规划路线。
```

```text
我对青铜器感兴趣，带我参观一下。
```

```text
带我去看青铜神树。
```

玄喵会生成导览计划，介绍第一站，再调用展线工具。页面确认真正到达后，玄喵才会继续讲解。

到达一站后可以输入：

```text
继续
```

系统会读取当前导览状态，前往下一站。路线完成后再说“继续”，玄喵会提示路线已经完成，而不会越界跳转。

如需换路线，可以说：

```text
重新规划一下
```

系统会取消当前路线，并结合当前位置和已浏览记录生成新路线。

## 9. 3D 数字馆与知识图谱

入口：顶部“3D数字馆”，地址 `/3dlist`。

### 9.1 选择文物

数字馆列表包含金面具残片、青铜纵目面具、青铜神树、三星堆金杖、青铜大立人像等展品。

1. 点击文物卡片。
2. 系统进入对应 3D 页面。
3. 等待模型和图谱加载。

### 9.2 3D 操作

- 拖动鼠标旋转。
- 滚轮缩放。
- 点击“重新加载”处理偶发的模型加载失败。
- 点击左上角返回按钮回到藏品列表。

### 9.3 图谱操作

1. 点击左侧或侧边的节点类型筛选按钮。
2. 点击具体节点查看节点说明和关系。
3. 点击“刷新图谱”重新加载数据。
4. 点击“重置视图”恢复图谱位置。
5. 如果节点提供跳转操作，可进入相关文物或继续讲解。

> 知识图谱展示的是系统整理的文化关系。复杂历史结论仍应结合资料来源和权威研究判断。

## 10. 全局玄喵使用教程

玄喵是页面右侧的全局悬浮 AI 助手。它会在多个前台页面中保持当前浏览上下文。

### 10.1 打开和关闭

1. 点击页面右侧的玄喵标签或头像。
2. 点击玄喵或提问入口打开“玄喵提问”窗口。
3. 点击窗口右上角 `x` 关闭提问框。
4. 点击回答气泡右上角 `×` 可以提前关闭气泡。
5. 玄喵正在说话时，点击气泡可停止当前讲解。

### 10.2 文字提问

1. 在输入框输入问题，最多 200 字。
2. 点击“提问”，或直接按 `Enter`。
3. 等待玄喵显示探索状态和最终回答。

适合的提问示例：

```text
青铜神树代表什么？
```

```text
它和祭祀有什么关系？
```

```text
今天是几号？
```

```text
成都今天天气怎么样？
```

### 10.3 语音提问

有两种操作方式。

#### 使用麦克风按钮

1. 点击“语音提问”。
2. 浏览器提示授权时选择“允许”。
3. 对着麦克风说话。
4. 再次点击按钮结束录音。
5. 等待系统识别。
6. 识别结果会先填入输入框。
7. 检查并修改文字，确认正确后再点击“提问”。

#### 使用 `V` 键

1. 在普通浏览状态按一次 `V` 开始录音。
2. 说完后再按一次 `V` 停止并识别。
3. 检查识别文字。
4. 修改错误内容后再提交。

玄喵空闲时会偶尔显示“按 V 键，和玄喵直接对话”的提示气泡。该提示只是快捷键说明，不会自动录音。

### 10.4 上传附件

1. 点击输入框下方的回形针按钮。
2. 选择文件。
3. 等待附件解析完成。
4. 在输入框中说明你希望玄喵做什么。
5. 点击“提问”。

当前悬浮玄喵最多同时保留 3 个附件，支持常见的：

- 文本：`.txt`、`.md`、`.csv`、`.json`。
- 文档：`.pdf`、`.doc`、`.docx`。
- 图片：JPG、PNG、GIF、BMP、WebP 等。
- 音频：MP3、WAV、M4A、OGG、FLAC 等。
- 视频：MP4、AVI、MOV、WMV、WebM 等。

复杂图片、长音频或视频建议优先使用“AI文博助手”，因为那里能显示附件状态、解析结果和完整对话历史。

### 10.5 让玄喵执行页面操作

玄喵可以执行部分真实工具操作。建议用明确的动词和对象。

| 目标 | 示例说法 |
|---|---|
| 打开页面 | “打开 3D 数字馆” |
| 搜索商品 | “打开商城搜索金面具文创” |
| 搜索文物 | “搜索青铜神树” |
| 打开展线 | “带我去看金面具” |
| 控制展线 | “打开青铜神树的 3D 展台” |
| 播放讲解 | “播放青铜神树语音介绍” |
| 查询时间 | “今天是几号？” |
| 查询天气 | “成都今天天气怎么样？” |

玄喵不会代替用户自动付款，也不会在未经确认的情况下生成收费图片。

### 10.6 上下文记忆

玄喵会记录轻量的短期参观状态，例如：

- 当前页面。
- 当前文物。
- 当前展线节点。
- 最近问题。
- 最近调用的工具和结果。
- 已经浏览过的文物。
- 当前正在执行的导览路线。

例如先打开金面具，再问“它为什么特别”，系统会把“它”理解为金面具。如果你已经切换到青铜神树，“它”会随当前文物更新。

## 11. AI 文博助手使用教程

入口：顶部“AI文博助手”，地址 `/ai-chat`，需要登录。

AI 文博助手适合完整对话、多模态分析、知识库问答和 AI 创作。

### 11.1 页面区域说明

页面主要分为：

- 左侧“玄喵探索”：新建、恢复和删除最近探索会话。
- 左侧快捷分类：热门问题、文物解说、文明知识、时空脉络。
- 中间消息区：显示问题、回答、探索过程、资料来源和作品卡片。
- 底部推荐问题：一键继续探索。
- 生图工具栏：切换快速或品质模式，打开“我的作品”。
- 输入区：输入文字、上传附件、语音输入和发送。

### 11.2 普通文字问答

1. 在底部输入问题。
2. 点击发送按钮，或按 `Enter`。
3. “玄喵正在探索”表示系统正在判断问题、查找资料或调用工具。
4. 回答正文会优先展示。
5. 回答结束后，探索过程会折叠为“玄喵探索过程 · 若干步 · 用时”。
6. 点击折叠区可查看游客能理解的探索步骤。
7. 点击“专家模式：查看 Agent 信息”，可查看 `route`、`tool`、参数和执行时长。普通使用者通常不需要展开这一层。

### 11.3 推荐问题与连续探索

- 点击左侧分类切换推荐问题主题。
- 点击消息下方“继续探索”按钮，可直接提出关联问题。
- 点击左侧探索记录可以恢复之前的会话、当前文物和导览状态。
- 点击左侧 `+` 新建探索。
- 点击垃圾桶删除不再需要的探索记录。

建议使用连续问法：

```text
介绍青铜神树。
```

然后继续问：

```text
它为什么重要？
```

再问：

```text
它和太阳崇拜有什么关系？
```

### 11.4 RAG 知识库与资料来源

当问题属于三星堆、金沙、文物、遗址、考古、青铜器、祭祀坑、古蜀文明等文博主题时，系统可能检索本地知识库。

回答完成后，如果检索到了有效资料，会显示折叠的“资料来源”：

1. 点击“资料来源”展开。
2. 查看资料标题和面向游客的说明。
3. 点击资料标题，可以在已配置的情况下跳转到 Obsidian 或打开对应资料。
4. 点击“专家信息”可查看路径、匹配度和检索类型。

以下情况通常不会显示知识库来源：

- 普通生活问题，例如“今天几号”。
- 图片、音频或视频分析。
- 只要求总结用户自己上传的文档。
- 没有达到有效检索条件的回答。

如果点击资料后出现 `Vault not found`，说明当前电脑的 Obsidian Vault 名称与系统配置不一致。参见[常见问题](#2112-点击资料来源后-obsidian-提示-vault-not-found)。

### 11.5 上传图片、音频、视频或文档

1. 点击回形针按钮。
2. 选择一个或多个文件。
3. 在发送前检查附件卡片，错误文件可点击 `×` 移除。
4. 输入具体任务。
5. 点击“发送”。

支持类型：

- 图片：常见图片格式。
- 音频：常见音频格式。
- 视频：常见视频格式。
- 文档：PDF、Word、TXT、Markdown。

页面限制：

| 类型 | 前端单文件建议上限 |
|---|---:|
| 图片 | 10 MB |
| 音频 | 50 MB |
| 视频 | 200 MB |
| 文档 | 20 MB |

视频分析默认最多处理约 120 秒。为了提高成功率，建议优先上传 10 至 60 秒、画面清晰、音轨正常的 MP4。

提问示例：

```text
请识别这张图片里的文物，并说明你判断的依据。
```

```text
请转写这段音频，再总结主要观点。
```

```text
请结合画面和声音总结这个视频。
```

```text
请概括这份文档的核心内容，不要使用外部知识补充。
```

### 11.6 麦克风语音输入

1. 点击麦克风按钮开始录音。
2. 再次点击结束录音。
3. 系统显示“正在识别语音”。
4. 识别文字会先进入输入框，不会立即发送。
5. 检查文字；如果有错，直接编辑。
6. 确认后点击发送。

### 11.7 视觉辅助建议

当玄喵认为一张示意图能帮助理解时，回答下方可能出现“玄喵的视觉辅助建议”。

例如询问：

```text
青铜神树为什么被认为和古蜀人的宇宙观有关？
```

操作方式：

1. 先阅读玄喵的文字回答。
2. 查看视觉辅助建议的标题和生成原因。
3. 点击“生成辅助示意图”确认生成。
4. 如果不需要，点击“暂不需要”。
5. 确认后会创建生图任务，作品卡片回到当前讲解中。
6. 生成成功后可放大、下载或再次生成。

系统不会只因为 AI 判断适合就自动产生费用，必须由用户点击确认。

### 11.8 资料可信度说明

- “AI辅助示意图”用于帮助理解，不代表考古原貌。
- “AI推测复原图”属于推测性表达，不是考古定论。
- AI 回答可能出错。用于正式研究、论文、讲解词时，应展开“资料来源”并核对原始文档。

## 12. AI 图片和视频创作

系统提供两种创作入口：

1. AI 文博助手：直接用自然语言描述图片或视频，适合在对话中创作。
2. 古蜀 AI 创作：提供模板、风格、比例、参考图、历史任务等完整设置。

### 12.1 在 AI 文博助手中生图

1. 进入“AI文博助手”。
2. 在“生图模式”中选择“快速”或“品质”。
3. 输入明确的画面描述，例如：

```text
生成一张三星堆青铜神树主题的博物馆展览海报，青铜绿和金色配色，画面庄重，不要文字。
```

4. 点击发送。
5. 观察作品卡片中的真实阶段和等待时间。
6. 生成成功后点击“放大”“下载”或“再生成”。

快速模式适合预览和节省等待时间；品质模式适合最终展示，通常更慢。

### 12.2 在 AI 文博助手中生成视频

输入带有明确视频意图的描述，例如：

```text
生成一段三星堆青铜面具在博物馆灯光下缓慢显现的视频，镜头缓慢推进。
```

如果使用参考图生成视频：

1. 只附加 1 张图片。
2. 输入希望画面如何运动。
3. 点击发送。

对话生图当前不使用参考附件；参考图片主要用于图生视频或独立创作页面。

### 12.3 使用“古蜀 AI 创作”页面

入口：三星堆探秘中的“立即体验”，地址 `/ai-image-generator`。

操作步骤：

1. 选择“图片”或“视频”。
2. 可选一个“创作模板”快速填写。
3. 在“创作描述”中写清主体、场景、风格、颜色、镜头和禁用内容。
4. 图片任务选择视觉风格：博物馆海报、文物复原、文化 IP、水墨古蜀、三维场景或科普卡片。
5. 图片任务选择快速模式或品质模式。
6. 选择画面比例：`1:1`、`4:3`、`3:4`、`16:9` 或 `9:16`。
7. 视频任务选择文字生成或图片生成视频。
8. 视频任务可以选择固定镜头、缓慢推进、缓慢拉远、向左摇镜或向右摇镜。
9. 如需排除不希望出现的内容，在“排除内容”中填写，例如“文字乱码、主体变形、低清晰度”。
10. 点击“开始生成图片”或“开始生成视频”。

生成中会显示任务阶段。不要连续重复点击生成按钮。

### 12.4 查看和管理作品

在 AI 文博助手中：

1. 点击“我的作品”。
2. 查看生成中和已完成数量。
3. 点击作品条目回到对应作品卡片。
4. 点击刷新按钮更新任务状态。

在古蜀 AI 创作页面中：

1. 在右侧或下方“创作历史”查看全部任务。
2. 点击历史任务查看结果。
3. 成功作品可以下载、收藏或分享；具体功能是否可用取决于浏览器和部署环境。
4. 失败图片可以点击“重试”。
5. 进行中的任务可以点击“取消任务”。

作品保存在当前登录账号下，刷新页面后仍可继续查看任务状态。

## 21. 常见问题与故障排查

### 21.1 页面完全打不开

可能原因：前端没有启动，或 `8800` 端口被占用。

处理：

1. 确认访问的是 `http://localhost:8800`。
2. 让系统维护者确认前端进程正在监听 `8800`。
3. 如果端口被旧进程占用，先停止旧进程再启动。

### 21.2 页面能打开，但列表为空或操作报网络错误

可能原因：后端、数据库或代理未正常运行。

处理：

1. 确认后端 `http://localhost:8889` 已启动。
2. 确认 MySQL 已启动，数据库配置正确。
3. 检查后端控制台是否有数据库连接错误。
4. 刷新前端页面重试。

### 21.3 点击 AI 文博助手后跳到登录页

这是正常权限控制。AI 文博助手需要登录。完成注册和登录后，系统会允许进入。

### 21.4 AI 显示“服务连接中断”或使用备用资料

可能原因：

- AI 模型密钥无效或额度不足。
- 模型服务网络超时。
- 后端未启动。
- 当前会话失效。

处理：

1. 先发送一个简短问题重试。
2. 新建探索会话后重试。
3. 让维护者检查后端日志和模型配置。
4. 不要在前端代码或浏览器中填写真实 API Key。

### 21.5 AI 回答需要等待数秒

AI 路由、知识检索、模型生成和语音合成是不同阶段。文博知识问题、多模态问题和生图任务会比简单日期问题更慢。

建议：

- 问题尽量清晰，一次只问一个核心问题。
- 视频尽量短。
- 生图预览优先使用快速模式。
- 等待当前任务完成后再创建新任务。

### 21.6 麦克风按钮不可用

处理顺序：

1. 使用 Edge 或 Chrome。
2. 检查浏览器麦克风权限。
3. 确认系统麦克风没有被其他软件独占。
4. 刷新页面。
5. 仍不可用时改用文字输入。

### 21.7 语音识别不准确

识别结果不会自动发送。请在输入框中检查并修改后，再点击提问或发送。建议在安静环境中说普通话，并保持麦克风距离稳定。

### 21.8 有文字回答，但没有声音

可能原因：浏览器自动播放限制、电脑静音、TTS 服务失败或模型额度不足。

处理：

1. 先点击页面任意位置，再重新提问。
2. 检查系统和浏览器音量。
3. 关闭其他正在播放音频的页面。
4. 文字正常时仍可继续使用，TTS 失败不会阻止文字回答。

### 21.9 玄喵气泡消失太快

1. 将鼠标移入玄喵面板或气泡区域，系统会延长阅读时间。
2. 在可滚动气泡中滚动内容时，自动隐藏会暂停。
3. 需要完整历史记录时，改用“AI文博助手”。

### 21.10 3D 模型加载失败或显示空白

1. 等待加载进度完成。
2. 点击“重新加载”。
3. 检查浏览器是否启用硬件加速。
4. 更新显卡驱动或换用 Edge/Chrome。
5. 低性能设备关闭其他占用显卡的应用。

### 21.11 图谱为空

1. 确认后端正常。
2. 点击“刷新图谱”。
3. 清空节点类型筛选。
4. 点击“回到中心”或“重置视图”。
5. Neo4j 未启用时系统可回退到 MySQL；如果两者数据都不完整，需要维护者补充数据。

### 21.12 点击资料来源后 Obsidian 提示 Vault not found

原因：链接中的 Vault 名称与本机 Obsidian 实际仓库名称不同。

处理：

1. 打开 Obsidian。
2. 确认左下角显示的 Vault 名称。
3. 让维护者把系统中的 `knowledge.vault-name` 配置为完全相同的名称。
4. 确认知识库文件路径存在。
5. 重启后端后重新点击资料。

如果当前电脑没有安装 Obsidian，仍可以阅读 AI 回答，只是不能使用本地协议跳转。

### 21.13 附件上传失败

1. 检查文件类型是否支持。
2. 检查文件大小。
3. 文件名尽量避免过长和特殊符号。
4. 视频建议使用 MP4，音频建议使用 WAV 或 MP3。
5. 删除失败附件后重新选择。
6. 确认后端上传目录有写入权限。

### 21.14 视频解析失败

可能原因：视频过长、编码不兼容、没有安装 FFmpeg、画面或音轨损坏。

处理：

1. 使用 120 秒以内的视频，演示建议 10 至 60 秒。
2. 转换为 H.264 编码的 MP4。
3. 确认视频可以在本机正常播放。
4. 让维护者确认 `ffmpeg` 和 `ffprobe` 可用。

### 21.15 AI 生图一直等待

1. 打开“我的作品”并点击刷新。
2. 不要重复提交同一个任务。
3. 等待外部模型服务返回；品质模式通常更慢。
4. 如果任务最终失败，查看错误信息并点击“重新尝试”。
5. 让维护者检查图片生成 API Key、余额、模型名称和后端任务调度日志。

### 21.16 AI 生图提示画面比例未配置

1. 在独立创作页明确选择一个画面比例。
2. 推荐先用 `1:1` 或 `4:3`。
3. 在 AI 文博助手中重试时，系统会使用当前生图配置。
4. 如果仍失败，让维护者检查后端图片生成比例映射配置。

### 21.17 活动报名失败

检查：

- 是否已登录。
- 活动是否处于报名中。
- 是否超过报名截止时间。
- 名额是否已满。
- 是否已经报名。

### 21.18 订单无法提交

检查：

- 是否已登录。
- 是否选择了完整的收货地址。
- 商品是否有库存。
- 数量是否有效。
- 商品是否仍处于上架状态。

### 21.19 支付按钮无法完成真实支付

当前部署可能使用演示或沙箱配置。请联系系统维护者确认支付宝、微信等支付渠道是否已配置。不要在不明确的演示环境中输入真实支付信息。

## 22. 本地启动与停止

本章面向负责演示或维护的人。普通游客如果已经拿到可访问地址，可以跳过。

### 22.1 环境要求

- JDK 17。
- Node.js 20 或 22 LTS。
- MySQL 8.x。
- Git。
- Neo4j 5.x，可选。
- FFmpeg，用于视频分析。

### 22.2 初始化数据库

首次部署时创建数据库并导入项目根目录下的 `heritage_db.sql`。PowerShell 中建议使用：

```powershell
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS sanxingdui_repro DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
cmd /c "mysql -u root -p sanxingdui_repro < heritage_db.sql"
```

### 22.3 准备后端配置

如果本机还没有真实配置文件：

```powershell
Copy-Item "springboot\src\main\resources\application-template.yml" "springboot\src\main\resources\application.yml"
```

然后由维护者填写：

- MySQL 用户名和密码。
- JWT 密钥。
- AI 对话模型密钥。
- TTS 密钥。
- 图片和视频生成密钥。
- 可选的 Neo4j 配置。
- Obsidian 知识库路径和 Vault 名称。

真实密钥不得写进本教程、前端代码或提交到 GitHub。

### 22.4 启动后端

新开一个 PowerShell 窗口：

```powershell
Set-Location "G:\终版\springboot"
.\mvnw.cmd spring-boot:run
```

看到应用启动完成且没有致命异常后，后端地址为：

```text
http://localhost:8889
```

### 22.5 启动前端

再开一个 PowerShell 窗口：

```powershell
Set-Location "G:\终版\vue3"
npm ci
npm run dev
```

首次安装依赖时执行 `npm ci`，之后通常只需执行 `npm run dev`。

前端地址为：

```text
http://localhost:8800
```

### 22.6 检查端口

```powershell
Get-NetTCPConnection -State Listen -LocalPort 8800,8889
```

两个端口都处于 `Listen` 才表示前后端都已启动。

### 22.7 停止服务

最安全的方式是在各自启动窗口中按：

```text
Ctrl + C
```

如果窗口已经关闭但进程仍在，可以先查看进程：

```powershell
Get-NetTCPConnection -State Listen -LocalPort 8800,8889 |
  Select-Object LocalPort, OwningProcess
```

确认 PID 确实属于本项目后再停止：

```powershell
Stop-Process -Id <PID>
```

不要在没有核对 PID 的情况下批量结束所有 Java 或 Node 进程，以免关闭其他项目。

### 22.8 基础构建检查

前端：

```powershell
Set-Location "G:\终版\vue3"
npm run build
```

后端：

```powershell
Set-Location "G:\终版\springboot"
.\mvnw.cmd -DskipTests package
```

## 23. 使用边界与安全提示

1. AI 回答是辅助信息，不应替代权威考古文献和专家结论。
2. AI 生成的复原图、场景图和视频必须保留 AI 内容标识。
3. 不要把身份证、银行卡、密码、未公开研究材料等敏感信息上传到 AI 对话。
4. 不要在前端环境变量、聊天记录、截图或 Git 仓库中公开 API Key。
5. 图片和视频生成可能产生费用，创建任务前确认使用的是快速还是品质模式。
6. 玄喵执行的是有限的系统工具。涉及付款、删除、发布等高风险操作时，应以页面确认和人工判断为准。
7. 管理员删除文物、课程、商品和活动前，应先确认业务关联并做好备份。
8. 在正式比赛或演示前，至少完成一次登录、AI 问答、展线跳转、TTS、生图和商城搜索回归测试。
