# 项目状态说明

本文记录当前公开版本的可运行能力、验证方式和已知边界。

## 1. 当前可用能力

| 能力 | 状态 | 说明 |
|---|---|---|
| 前端启动 | 可用 | Vue 3 + Vite，默认端口8800 |
| 后端启动 | 可用 | Spring Boot 3，默认端口8889 |
| 文物浏览 | 可用 | 支持文物列表、详情和筛选 |
| RAG问答 | 可用 | 38份 Markdown 文档，支持来源回传 |
| Agent路由 | 可用 | 工具调用、RAG、直接回答和不支持四类结果 |
| 工具安全 | 可用 | 白名单、参数校验、超时和降级 |
| 三维展示 | 可用 | 5件核心 GLB 文物模型 |
| 图谱探索 | 可用 | AntV G6；Neo4j可选，MySQL可回退 |
| 图片多模态 | 可用 | 需要配置视觉模型服务 |
| 图片/视频创作 | 可用 | 需要配置对应媒体服务 |
| UI回归 | 可用 | 本地 Playwright/Node 脚本 |

## 2. 当前验证方式

### 前端

```powershell
cd vue3
npm ci
npm run build
```

### 后端

```powershell
cd springboot
.\mvnw.cmd -DskipTests package
.\mvnw.cmd test
```

### 页面入口

- `http://localhost:8800/tanmi`
- `http://localhost:8800/trail`
- `http://localhost:8800/3dlist`
- `http://localhost:8800/ai-chat`
- `http://localhost:8800/ai-image-generator`

### 回归范围

回归脚本覆盖知识索引、典型问题、来源标记、Agent路由、未知工具拦截、上下文恢复、图谱、导览、语音、视觉辅助和媒体生成等流程。

## 3. 已知边界

- 当前主检索是自定义词法索引，不是 BM25 或向量数据库；
- 当前没有正式的 Precision、Recall、F1 和人工答案质量评分；
- 当前没有固定 chunk size/overlap，主要按文档索引并控制上下文长度；
- Neo4j不是强制依赖，关闭后使用 MySQL 结构化关系；
- Three.js和G6通过实体 ID 关联，尚未实现完整的三维网格点击双向联动；
- 没有模型 API Key 时，AI问答和媒体创作无法完整运行，但基础页面可以启动；
- 课程视频等大文件不进入 Git，缺少视频时课程页显示文字章节；
- 回归脚本目前主要本地执行，尚未接入完整的 GitHub Actions CI。

## 4. 配置注意事项

真实配置文件复制自 `application-template.yml`，其中的数据库密码、JWT密钥、模型密钥和图谱密码只保存在本地。不要把 `application.yml`、日志、`target`、`dist`、上传文件和临时目录提交到仓库。
