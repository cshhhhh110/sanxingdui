## 第二步：我改代码（P0，半天，你完成第一步后触发）

### 2.1 新建知识检索模块
文件：`G:\终版\vue3\src\utils\knowledgeSearch.js`

功能：
- 加载 `public/data/knowledge-*.txt` 全部文件
- 用户提问 → 对每个文档计算匹配分数
  - 精确关键词匹配：标题词、实体ID、专有名词 → 高权重
  - 模糊匹配：问题词与文档内容的重叠度 → 中权重
- 返回 top-3 最相关的文档片段

### 2.2 新建 MiMo 对话 API
文件：`G:\终版\vue3\src\api\MiMoChatApi.js`

功能：
- 直接从前端调 `https://token-plan-cn.xiaomimimo.com/v1/chat/completions`
- `api-key` 头，`mimo-v2.5-pro` 模型
- 支持流式 SSE

### 2.3 重构 `submitQuestion` 逻辑
文件：`G:\终版\vue3\src\components\Live2DAvatar.vue`

新流程：
```
用户提问
  ↓
knowledgeSearch(question) → top-3 相关文档
  ↓
拼装 RAG prompt：
  "你是玄喵，三星堆虚拟导游。
   根据以下资料回答用户问题。
   如果资料不足以回答，诚实说不知道。
   
   【参考资料】
   1. {文档1内容}
   2. {文档2内容}
   3. {文档3内容}
   
   【用户问题】
   {question}"
  ↓
调 MiMo API → 流式返回
  ↓
打字机效果展示回答
```

### 2.4 删除旧依赖
- 删除 `chatReplyConfig.js` 的固定关键词匹配
- 删除 WebSocket 发送逻辑（保留 WS 连接用于其他功能，玄喵问答不再依赖它）
- 保留 `startTypewriterEffect` 打字机效果

### 2.5 兜底策略
- MiMo API 超时/失败 → 提示"喵～网络不太好，稍后再问我吧"
- 知识库没匹配到任何文档 → "这个问题超出我的知识范围了，试试问我青铜神树或黄金面具吧"
